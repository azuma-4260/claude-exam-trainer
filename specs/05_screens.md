# 05. 画面設計(v1.2・モバイルファースト)

## 全体構造

- 下部タブ(スマホ)/ サイドバー(PC): **Home / Study / Mock / Stats**。CCAR-F 固定
- 1 画面 1 目的、学習系は片手タップ完結。実装時は `frontend-design` スキルに従う
- ダークモード: shadcn/Tailwind の標準対応で追加工数ゼロなら実装、専用調整が必要なら試験後
- Study/Mock 画面への進入時にキュー/セッション取得を行う(これが Neon の実質的な warm-up。keep-alive は禁止)

## S-1 Home

- カウントダウン + 今日の進捗リング(予算消化)
- 「今日のノルマ」(45 分予算)と「バックログ」(件数のみ)を分離表示
- CTA「今日のキューを始める」1 ボタン。pace_warning 時のみ警告カード。9/20〜は推奨行動カード

## S-2 Study(ハブ)

- Quick Drill / Practice / 間違いノート / シラバスマップ
- シラバスマップ: 3 階層アコーディオン、習熟度バー、問題 0 に ⚠、トピック限定演習

## S-3 Quick Drill

- フラッシュ: タップ裏返し → Again / Hard / Good / Easy
- 短問 MCQ: 選択 → 即時正誤(評価ボタンなし)
- **保存 UI(厳密 ACK)**: 正誤・解説は選択直後に表示。サーバー保存中は **Next のみ disabled**(問題・回答・解説は操作可能なまま)。ACK 成功で Next 活性化。失敗時は回答状態を保持し「保存に失敗しました / Retry」。自動巻き戻し・次問先行・outbox は実装しない
- サマリ: flash は rating 分布、MCQ のみ正答率
- 悪問フラグは右上メニュー

## S-4 Practice

- シナリオ文折りたたみ、選択 → Answer → 即時採点、全選択肢の解説 + refs
- Next の活性化は S-3 と同じ ACK ルール
- 解放済みフォーム問題には「模試出題済み」バッジ(FSRS 非対象であることの説明は不要、表示のみ)

## S-5 Mock

- 開始画面: フル(未実施フォームを自動選択・availability 検証結果を表示)/ ドメイン別ミニ。「フルは一時停止・破棄不可。閉じても再開できるが時計は進む」を明示。availability NG のフォームは理由(未解決フラグ n 件)と共に選択不可表示。提出済みフォームの再受験は「rehearsal」ラベル付きで選択可
- 試験中: 残り時間(deadline_at - now 毎秒再計算)、n/60、見直しフラグ、シナリオ見出し + 設問群、問題一覧グリッド(回答済/フラグ/未回答)。回答・フラグ・位置は操作ごとに即時保存
- 復元: 進行中セッションがあれば「再開」を最優先表示。deadline 超過検知時は timeout 提出してレポートへ
- 採点・解説は提出まで非表示

## S-6 模試レポート

- 素の正答率(大)+ 85% ライン、ドメイン別横棒(重み併記)、誤答一覧(タップで解説)
- rehearsal の場合はヘッダに明示し、readiness 判定外であることを注記
- 「弱点ドメインのミニ模試」ショートカット

## S-7 間違いノート

- attempt 導出リスト(誤答回数順)、連続正解 n/3 表示、「総ざらい開始」(practice mode)

## S-8 Stats

- ドメイン別習熟度、日別回答数、模試推移(initial / rehearsal 別系列)。優先度低・簡略表示可

## S-9 設定

- データエクスポート、未解決フラグ一覧(現行 rev のみ)、ログアウト
- パスコード変更 UI なし(Vercel 環境変数で変更)

## 認証フロー

`POST /login` → APP_PASSCODE 照合 → SESSION_SECRET 署名トークンを HttpOnly; Secure; SameSite=Lax の長期 Cookie に。パスコード自体は Cookie に入れない。詳細は `06`。
