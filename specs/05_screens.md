# 05. 画面設計(v1.3・モバイルファースト)

**v1.3(2026-09-29, S-3)**: 「CCAR-F 固定」を廃止し、学習スコープ(F / P / F+P)の表示・切替導線、exam 別カウントダウン、Mock の exam ラベル・進行中セッションのスコープ非依存を追加。

## 全体構造

- 下部タブ(スマホ)/ サイドバー(PC): **Home / Study / Mock / Stats**
- **学習スコープ(v1.3、`01` FR-10)**: 現在のスコープ(F / P / F+P)を Home ヘッダに常時表示し、切替は S-9 設定と Home ヘッダから行う。切替後は Home / Study / Mock / Stats がスコープ基準で再取得される。未設定の試験日を持つ exam を含むスコープは選択肢に出さない(またはサーバー拒否をエラー表示)
- 問題・フォーム・ドメインには、スコープ `both` のとき exam ラベル(F / P)を付ける
- 1 画面 1 目的、学習系は片手タップ完結。実装時は `frontend-design` スキルに従う
- ダークモード: shadcn/Tailwind の標準対応で追加工数ゼロなら実装、専用調整が必要なら試験後
- Study/Mock 画面への進入時にキュー/セッション取得を行う(これが Neon の実質的な warm-up。keep-alive は禁止)

## S-1 Home

- カウントダウン(スコープ内で試験日が未来の exam。複数あれば各々。試験日を過ぎた exam は「受験済み」表示)+ 今日の進捗リング(予算消化)
- 「今日のノルマ」(45 分予算)と「バックログ」(件数のみ)を分離表示
- CTA「今日のキューを始める」1 ボタン。pace_warning 時のみ警告カード(`both` ではどの exam の警告かを表示)。単独スコープの直前期(試験日 − 7 日〜)は推奨行動カード(`04` §直前期と D-1)

## S-2 Study(ハブ)

- Quick Drill / Practice / 間違いノート / シラバスマップ
- シラバスマップ: 3 階層アコーディオン、習熟度バー、問題 0 に ⚠、トピック限定演習

## S-3 Quick Drill

- フラッシュ: タップ裏返し → Again / Hard / Good / Easy(評価を選ぶと解説を表示。**評価は Next を押すまで何度でも変更可**)→ **Next で保存**(v1.2.3 / D4-4)。保存中は Next が「保存中…」で disabled、ACK 成功で**自動的に次問へ**進む(二度押し不要)。失敗時は評価を保持し「保存に失敗しました / Retry」
- 短問 MCQ: 選択 → 即時正誤(評価ボタンなし)。選択 = 送信
- **保存 UI(厳密 ACK)**: 正誤・解説は選択直後に表示。サーバー保存中は **Next のみ disabled**(問題・回答・解説は操作可能なまま)。MCQ は ACK 成功で Next 活性化。失敗時は回答状態を保持し「保存に失敗しました / Retry」。自動巻き戻し・次問先行・outbox は実装しない
- サマリ: flash は rating 分布、MCQ のみ正答率
- 悪問フラグは右上メニュー

## S-4 Practice

- シナリオ文折りたたみ、選択 → Answer → 即時採点、全選択肢の解説 + refs
- Next の活性化は S-3 と同じ ACK ルール
- 解放済みフォーム問題には「模試出題済み」バッジ(FSRS 非対象であることの説明は不要、表示のみ)

## S-5 Mock

- 開始画面: 候補は学習スコープ内の exam のフォーム / ドメインのみ(`both` では exam ラベル付き)。フル(exam ごとに未実施フォームを自動選択・availability 検証結果を表示)/ ドメイン別ミニ。「フルは一時停止・破棄不可。閉じても再開できるが時計は進む」を明示。availability NG のフォームは理由(未解決フラグ n 件)と共に選択不可表示。提出済みフォームの再受験は「rehearsal」ラベル付きで選択可
- 試験中: 残り時間(deadline_at - now 毎秒再計算)、n/フォームの問題数(CCAR-F は 60。P は T-pmock で確定)、見直しフラグ、シナリオ見出し + 設問群、問題一覧グリッド(回答済/フラグ/未回答)。回答・フラグ・位置は操作ごとに即時保存
- 復元: 進行中セッションがあれば「再開」を最優先表示。**進行中セッションは学習スコープに関係なく表示・再開・提出できる**(スコープ外の exam のセッションでも隠さない。時計は止まらないため。`03` §exam_session)。deadline 超過検知時は timeout 提出してレポートへ
- 採点・解説は提出まで非表示

## S-6 模試レポート

- exam を明示。素の正答率(大)+ 85% ライン、ドメイン別横棒(重み併記)、誤答一覧(タップで解説)
- rehearsal の場合はヘッダに明示し、readiness 判定外であることを注記
- 「弱点ドメインのミニ模試」ショートカット

## S-7 間違いノート

- 学習スコープ内の exam のみ(`both` では exam ラベル付き)。attempt 導出リスト(誤答回数順)、連続正解 n/3 表示、「総ざらい開始」(practice mode)

## S-8 Stats

- 学習スコープ内の exam を集計(`both` では exam ごとにセクションを分ける)。ドメイン別習熟度、日別回答数、模試推移(initial / rehearsal 別系列)。優先度低・簡略表示可

## S-9 設定

- 学習スコープの切替(F のみ / P のみ / F+P)、データエクスポート(全 exam / exam 別)、未解決フラグ一覧(現行 rev のみ。スコープに関係なく全 exam を exam ラベル付きで表示)、ログアウト
- パスコード変更 UI なし(Vercel 環境変数で変更)

## 認証フロー

`POST /login` → APP_PASSCODE 照合 → SESSION_SECRET 署名トークンを HttpOnly; Secure; SameSite=Lax の長期 Cookie に。パスコード自体は Cookie に入れない。詳細は `06`。
