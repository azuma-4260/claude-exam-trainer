# 解放問題への本番 Practice 回答で applied_rating=null になる「正の証拠」が未取得(負の証拠と統合テストのみ)

## 内容

D3-4 の本番 E2E(2026-09-22)では、form A 提出後の解放と holdout を `verify:release` の機械検証
(本番 export に対して本番と同じ `evaluatePool` を実行)で確認したが、form A 収載問題への本番 Practice 回答は
0 件のため、`applied_rating=null` は「非 mock attempt 0 件・srs_state 0 件」という負の証拠と
D2-1 の統合テスト(`src/lib/practice/serve.test.ts`)に依っている。本番の実回答で null になった正の証拠は無い。

## 再現手順 / 根拠

1. 本番 Practice の現在バッチで form A 問題は 19・20 問目(f-d1-q201 / q202、released=true)にあり、
   Practice にはページ送りが無いため到達に 18 問の回答が必要(計画の上限 5 問を超えるためオーナー判断で見送り)
2. `npm run verify:release -- <export.json> --form form-a` の [B] 行が「practice 0 件」

## 推奨対応

- オーナーが通常の学習で form A 収載問題を Practice で回答した後、または M4(form B 提出)直後の
  `verify:release` 再実行で [B] の practice 件数が 1 以上・失敗 0 件になることを確認して closed にする。
  コード変更は不要
