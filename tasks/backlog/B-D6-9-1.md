# audit:form の問題形式の目安が、まとめ形式(D6-8)を使う場合の目安に未対応

## 内容
D6-9 で `audit:form` に問題形式・difficulty の分布表示と目安外 warning を追加した(`FORM_DISTRIBUTION_GUIDE`)。形式の目安は `07` §P 制作指針の「まとめ形式を使わない場合」(single 43〜48 / multi 15〜20)だけを持つ。

まとめ形式の型(Yes/No Matrix・Drop-down Matching)はまだスキーマに無い(T-bundle / D6-8)。そのため「使う場合」の目安(single 30〜35 / multi 15〜20 / Yes/No 5〜8 / Drop-down 5〜8)は実装していない。D6-8 で型が入ると、形式の集計(`FormDistribution.types`)が single / multi の 2 種のままになり、まとめ形式の件数は表示されない。warning も「使わない場合」の目安のまま出る。

## 再現手順 / 根拠
- `scripts/audit-form-mcq.ts` の `FORM_DISTRIBUTION_GUIDE` と `FormDistribution`
- `specs/07_content-pipeline.md` §P 制作指針「フォームの目安」

## 推奨対応
D6-8 でまとめ形式の type を追加するときに、次の 2 点を同じ変更で行う:
- `FormDistribution.types` に新しい型を足す。
- フォームにまとめ形式が 1 問でもあれば「使う場合」の目安で判定する。

warning のみなので停止条件には当たらない。
