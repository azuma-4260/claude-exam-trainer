# 過去の提出済み模試レポートへの再閲覧導線が無い(提出直後の遷移と timed_out 検知時のみ)

## 内容

D3-3 で `/mock/report/[sessionId]` は任意の提出済みセッションを表示できるが、URL に到達する導線は
「提出直後の自動遷移」と「start-screen での timed_out 検知バナー」の 2 つだけ。ブラウザを閉じた後に
過去のレポート(initial / rehearsal とも)を開き直す UI が無い。

## 再現手順 / 根拠

模試を提出 → レポート表示 → `/mock` に戻る → 再びレポートを見る手段が URL 直打ちしかない。

## 推奨対応

S-8 Stats の「模試推移(initial / rehearsal 別系列)」(D4-3)で各受験をレポートへのリンクにする。
D4-3 の実装時に本項目を absorb する。
