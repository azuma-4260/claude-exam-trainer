# P 独立 MCQ の ID 番号規則(帯)と連番検査が未定義

## 内容
F は ID 番号帯(flash q001〜 / C3a q101〜 / C5 q501〜)で種別を分け、`audit:practice` が帯ごとの連番を検査する。
P の独立 MCQ(CP3)の ID 規則は spec に無いため、D6-3 の `audit:practice --exam ccar-p`(独立 MCQ プロファイル)は
「form 非収載の MCQ 全件」を対象とし、帯・連番を検査しない。flash(q001〜 連番)と番号が衝突しない採番規則が要る。

## 再現手順 / 根拠
- `scripts/audit-practice-mcq.ts` ヘッダ / `PRACTICE_PROFILE`

## 推奨対応
CP3 着手時に P の MCQ 番号帯を `content/ccar-p/SOURCES.md`(F の §9 相当)に決め、必要なら独立 MCQ プロファイルに連番検査を足す。
