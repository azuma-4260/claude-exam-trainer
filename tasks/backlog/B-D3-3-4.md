# attempt 欠落時にレポートの素点と誤答一覧・ドメイン集計が自己矛盾し得る

## 内容

`buildMockReport` は attempt 欠落問題を「未回答=誤答」として誤答一覧・ドメイン集計に補完する一方、
全体素点は `session.score_raw` を優先するため、両者のソースが食い違うと表示が自己矛盾する
(例: score_raw=60 で attempt 1 件欠落 → 全体 60/60 なのに誤答一覧 1 問)。
Codex 敵対的レビュー(2026-08-27)の medium 指摘。

## 再現手順 / 根拠

specs/03 §Mock の attempt 生成では提出トランザクションが全問題の attempt を一括生成するため、
欠落は不変条件違反(通常起きない)。起きた場合のみ防御パスが矛盾表示になる。

## 推奨対応

`attempts` 件数 ≠ 出題数のとき `unknownQuestionIds` と同様の整合性警告をレポートに明示し、
素点もレポート内では単一ソース(attempt 導出)に統一する。
