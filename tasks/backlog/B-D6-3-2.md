# フォーム構造の定数が CCAR-F 固有値のまま(P フォームは現状 validator が拒否)

## 内容
- `mockFormSchema` の `question_ids` 長さ = `MOCK_FORM_SIZE`(60)、validator の `FORM_SCENARIO_COUNT`(4)はいずれも F の値で exam 非依存
- `FORM_DOMAIN_QUOTA["ccar-p"]` は未定義。D6-3 で P の `syllabus.yaml` は `form_questions` を書かない形に確定した(`03` §1)
- P の `mock_forms.yaml` は「固定フォーム配分が未定義」で validator が拒否する(fail closed。意図どおり)
- `audit:form` のシナリオ件数 warning(12〜18)は F のみ適用(`SCENARIO_SIZE_RANGE_BY_EXAM`)

## 再現手順 / 根拠
- `scripts/validate-bank.test.ts`「P の form は配分未確定のため拒否」

## 推奨対応
T-pmock で `03` §mock_forms に P の構造(問題数・配分・シナリオ有無・選択数)を確定(オーナー承認)し、D6-4 で
`MOCK_FORM_SIZE` / `FORM_SCENARIO_COUNT` を exam 別化、`FORM_DOMAIN_QUOTA["ccar-p"]` を追加、P の syllabus に
`form_questions` を追記、必要なら `SCENARIO_SIZE_RANGE_BY_EXAM` に P を追加する。
