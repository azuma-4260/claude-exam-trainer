# Practice 追補層(第 2 層)の出題順に topic priority 加重が無い

## 内容
D2-1 の Practice 出題は「日次キューの practice 項目(優先度反映済み)→ FR-4 プール残の id 昇順 + 同一シナリオ隣接」の 2 層。第 2 層の順序は決定的だが習熟度・ドメイン重みを反映しない(04 の priority 式は Drill/新規導入用で、Practice の順序は spec 未規定)。

## 再現手順 / 根拠
`src/lib/practice/serve.ts` の `assemblePracticeView` 第 2 層は id 昇順ソートのみ。C3a 反映後に問題数が増えると、弱点ドメインより先に id 順で若いシナリオが常に先頭に来る。当日回答済みは除外されるためローテーションはする。

## 推奨対応
実データ(C3a merge 後)で UX を見てから判断。加重するなら `topicPriorities`(`src/lib/queue/proficiency.ts`)を第 2 層のソートキーに混ぜる(`srsRows` / `correctQuestionIds` は loadPracticeView が既にロード済みの `loadQueueSignals` から取れる)。
